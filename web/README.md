# Phiano Web Dashboard (`web/`)

Interactive web visualization dashboard for inspecting the Phiano continuous phase manifold, phasor circles, Kuramoto synchronization, and real-time persona chat.

---

## Tech Stack

- **Vite** — Fast frontend build tool and dev server
- **React + TypeScript** — UI components and state management
- **Canvas / WebGL** — Real-time continuous phase circle & phasor visualization

---

## Development

```bash
cd web
npm install
npm run dev
```

The web dashboard connects to the Phiano REST API server running on `http://localhost:3000`.
