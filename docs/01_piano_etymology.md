# 01 — Phiano Etymology: From Piano to Phasor

## The Name

```
  PIANO  ───────────────────────►  PHIANO
  │                                  │
  ├─ Italian: "soft/loud"            ├─ Phasor + Piano
  ├─ Musical instrument              ├─ Phase manifold instrument
  ├─ 88 keys → continuous spectrum   ├─ Words → continuous phase space
  ├─ Harmonics & resonance           ├─ Spectral interference & resonance
  └─ Player piano = self-playing     └─ Self-organizing semantic space
```
